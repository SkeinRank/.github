# SkeinRank organization profile

This repository contains the public GitHub organization profile for **SkeinRank**.

## Files that drive the profile

- `profile/README.md` — the public organization landing page.
- `profile/assets/` — light and dark SVG artwork used by the landing page.
- `.gitignore` — local hygiene for the profile repository.

## Featured repositories

1. [`claim-plane`](https://github.com/SkeinRank/claim-plane) — control plane for verifiable AI engineering.
2. [`agent-lexicon`](https://github.com/SkeinRank/agent-lexicon) — deterministic terminology layer for coding agents.
3. [`skeinrank`](https://github.com/SkeinRank/skeinrank) — domain language control plane for search, RAG, and agent workflows.
4. [`agent-lexicon-benchmark`](https://github.com/SkeinRank/agent-lexicon-benchmark) — benchmark runs and evidence for Agent Lexicon.
5. [`skeinrank-benchmark`](https://github.com/SkeinRank/skeinrank-benchmark) — reproducible SkeinRank benchmark outputs.
6. [`oss-drift-report`](https://github.com/SkeinRank/oss-drift-report) — terminology drift measurements on open-source projects.
7. [`skeinrank.github.io`](https://github.com/SkeinRank/skeinrank.github.io) — public documentation site.
8. [`.github`](https://github.com/SkeinRank/.github) — organization profile and shared community files.

## Notes

Keep the organization profile compact and high-signal:

- use the hero and project cards for top-level positioning;
- keep install commands short;
- link out to each repository for deep technical details;
- keep benchmarks and evidence visible, but do not overload the front page.
